# FullTemplate

to use the template follow these steps:
- git clone https://github.com/mooHamza/MyTemplate.git C:\Templates\MyTemplate
- dotnet new install C:\Templates\MyTemplate
- dotnet new fulltemplate -n MyNewApp -o MyNewApp -> the two upper steps done once , so use template direct with line 3 

for tylor template 
- dotnet new install Clean.Architecture.Solution.Template
- dotnet new list ca-sln
- dotnet new ca-sln -n MyNewApp
