# FullTemplate

to use the template follow these steps:
- git clone https://github.com/mooHamza/MyTemplate.git TestClone
- dotnet new install ./TestClone
- dotnet new fulltemplate -n MyNewApp -o MyNewApp

for tylor template 
- dotnet new install Clean.Architecture.Solution.Template
- dotnet new list ca-sln
- dotnet new ca-sln -n MyNewApp
